# Manual checkpoint checks (not run)

- [ ] C1 Discovery: discover one robot, then two robots; verify unique devices and bounded scan timeout.
- [ ] C2 Arm: verify X/Z directions, 20 Hz output, +/-0.20 m/s clamp and 0.03 m step limit; NaN/Inf, disarm, close and 0.25 s silence stop new increments. Tracked arm actions take priority; rearming never replays cached commands.
- [ ] C3 Bridge: install `ros-humble-compressed-image-transport`, build `robomaster_image_transport`, and source the overlay. Run `ros2 run robomaster_image_transport compressed_republisher`; feed best-effort `/image` and verify `/image/compressed` decodes with matching headers and volatile/depth-1 QoS. A broken plugin must fail startup.
- [ ] C4 Cameras: build with `colcon build --symlink-install --packages-up-to robomaster_ros2`, source the overlay, and enable cameras with keyboard control disabled and motion disarmed. Check front/bottom/EP raw and compressed feeds, colors, headers, FPS/bandwidth and remapping. Missing plugin or killed bridge reports failure; disabled cameras, removal/re-addition and shutdown leave no stale bridges.
- [ ] C5 Diagnostics: build `robomaster_examples`, source the overlay, and run `ros2 run robomaster_examples fleet_stress_test --mode diagnostic` for the configured five-drone/two-robot fleet. Verify service failures/latencies, best-effort camera counts and continuous telemetry; silent hit/command topics cause no failures. Diagnostic mode sends no motion; motion mode rejects missing confirmation and cleans up on interruption.
